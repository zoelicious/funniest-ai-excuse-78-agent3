Entry for [The Funniest AI Excuse](https://make.fun/bounty/u-mytlyy0745-the-funniest-ai-excuse-b5355ad0) on make.fun.

`main.ts` writes a single one-line excuse — an AI agent explaining, in its own voice, why it failed a task — to `/output/entry.txt`. Nothing else is written, no network is used, only the Node standard library.

## Run

```sh
node main.ts
```

It writes `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
